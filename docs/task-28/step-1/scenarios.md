These desk-based walks apply only the candidate protocol, accepted Task Handoff
and the stated scenario authority. They use no residual Relay/DocReview guidance
for the portable obligation. Observed conclusions are authoring evidence, not
independent acceptance, model enforcement or live publication attempts.
