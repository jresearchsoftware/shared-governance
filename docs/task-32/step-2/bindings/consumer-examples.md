# Frozen consumer binding examples — read-only, not activation

These small overlays exercise whether the same [template](../bootstrap-template.md)
can route distinct owners. They are research fixtures using Step 1's accepted
inventory, not newly verified live settings, installed-runtime qualification,
complete replacement Instructions or consumer migration proposals. Both use
the temporary **read-only** trial role. The common template stays unchanged.
No consumer source or policy is copied into the shared package.
