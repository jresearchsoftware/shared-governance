Mark each read **OBSERVED**, **MODEL-REPORTED ONLY**, **UNAVAILABLE**,
**TRUNCATED**, **SIMULATED** or **NOT APPLICABLE with rationale**. Record exact
refs/URLs and content sufficient to establish what was read. A citation in the
answer without visible supporting retrieval is not independently observed access.
No need to capture unrelated files or compute fresh hashes for every message.

Evaluator: `<independent person/context and attribution>`. Explain the decision
against the case's primary facts: actual loader initiation, substantive coverage,
correct authority/permissions, specific gaps, findings and warning disposition.
Record mistakes, unsolicited mutations/tool calls, and costly unnecessary reads.
Missing evidence is distinct from a demonstrated source defect.

Two separate judgments:

- **Decision correctness:** CORRECT / PARTIAL / INCORRECT / UNASSESSABLE, with
  rationale. Correctly refusing unsupported PASS can be CORRECT.
- **Case qualification:** OBSERVED SUFFICIENT / PARTIAL / FAILED / UNQUALIFIED,
  with inspected/missing scope. A safety-correct answer with unavailable primary
  access leaves a positive-evidence case UNQUALIFIED. NOT RUN is never a PASS.

For each material warning or gap record source, impact, disposition, next useful
action, missing proof and effect on the judgment. Supported `none observed` means
only the inspected named surfaces; unavailable annotations are not “zero warnings”.

Pair comparison: `<difference versus control, equal performance, cost/context
confounds, retained failures and any separately labelled follow-up>`. State which
evidence supports a possible benefit. Model claims, correct saved text, local
validator success and green CI alone do not establish that benefit.

Owner disposition after independent assessment: `<continue deliberation / correct
prototype / reject / authorize another trial / separately adopt>`. A small observed
trial neither authorizes formal acceptance nor proves general reliability, settings
rollout, native review identity, package publication or consumer migration.
