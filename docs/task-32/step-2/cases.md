# Read-only behavioral cases

All cases are **NOT RUN / UNQUALIFIED** in Step 2. The prompts below are future
model inputs, not authority for this executor. Use identical prompts/fixtures in
both arms. Never paste this case's expected outcome, the bootstrap or the semantic
map into the control. For C8 only, both arms receive the same small example
binding because that case tests consumer routing rather than hidden project facts.

Record actual reads versus reported reads and assess semantic correctness using
[the capture sheet](capture-sheet.md). No scripted assertion decides model PASS.
No review, comment, ready label, Task launch, setting, secret or repository mutation
is permitted in any case. “Positive” means a sufficiently supported substantive
non-approving analysis, not a native APPROVE.
