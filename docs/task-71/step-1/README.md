## Bounded semantic baseline and change

The baseline is the complete accepted Task Handoff protocol, PC-001–013,
RA-001–006, PV-001–017, SA-001–009, the local manual binding, release policy and
native self-adoption instructions. Independent Review's complete methodology
defines the later assessment boundary; this document is executor qualification,
not independent acceptance. Relay 3.0.0's accepted workflow distinguishes native
automatic, native manual and explicitly authorized standalone routes; its
authenticated mechanisms are consumer-owned. Historical Task evidence and
frozen packages are retained, not rewritten as current dispatch rules.

| Material behavior | Candidate coverage and disposition |
