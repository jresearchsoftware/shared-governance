zero new mandatory scans, labels or operator actions. Separately adopting SI
adds one ordinary Issue/label per deferred independently actionable correction,
a bounded repository search and relevant-candidate reading at a suitable planning
opportunity, explicit owner notification and existing scope/link/disposition work.

controller, approval stage or cross-repository scan exists. The cheapest declined
alternative is retaining local conventions; the owner selected this opt-in topic
to improve discoverability without forcing it on current consumers. Forgotten
labels and stale candidates remain human workflow risks, surfaced by ordinary
discovery/reconciliation rather than preventive infrastructure.

in its in-tree registry and regenerates the lock/slot/boot. Relay stays at public

consumer, change a live label/setting, or publish a package. Concurrent package PRs
