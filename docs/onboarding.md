# Project onboarding

The [operator procedure](../packages/development-governance/vibevm/vibespecs/guides/onboarding.md)
and its [worked examples](../packages/development-governance/vibevm/vibespecs/guides/onboarding-examples.md)
are carried in the Development Governance package. Start with an explicit request:
**“Onboard this project to Shared Governance.”** The installed compact boot links
to the procedure only for that request; ordinary sessions skip the detail.
Reading or installing it adopts no topic and grants no settings-change authority.

The earlier repository-only delivery is retained in [Step 1 history](https://github.com/jresearchsoftware/shared-governance/blob/878f46400612b3300f21ef293ace4d8affff72b1/docs/onboarding.md).
[Step 2](task-30/step-2/README.md) records packaged delivery and its qualification.
